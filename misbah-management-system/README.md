# 📿 نظام عبق الكهرب - إدارة المسابيح والمبيعات والمخزون

نظام داخلي متكامل واحترافي لإدارة تجارة ومزادات المسابيح، العملاء، المخزون، المبيعات، ومستحقات أصحاب المسابيح.

---

## 🌟 مميزات النظام

- **واجهة عصرية فاخرة (Dark Gray Theme)** مريحة للعين وسهلة الاستخدام.
- **تجاوب كامل (Responsive)** مع كافة الأجهزة (الهاتف المحمول، التابلت، اللابتوب، الكمبيوتر).
- **خيار "أخرى" التلقائي** في كافة القوائم المنسدلة لإدخال خيارات مخصصة.
- **حساب الأرباح الآلي**:
  - أقل من 100 د.ك ⬅ ربح **5 د.ك**.
  - 100 د.ك أو أكثر ⬅ ربح **5% من السعر الأصلي**.
  - سعر البيع = **السعر الأصلي + الربح**.
- **إدارة العملاء** وتتبع حسابات TikTok وحالات الاعتماد والدفع والاستلام.
- **إدارة المبيعات والفواتير** مع طباعة فورية للفواتير وسندات القبض.
- **متابعة مستحقات أصحاب المسابيح** وتسجيل دفعات السداد.
- **لوحة تحكم إحصائية Dashboard** مع رسوم بيانية لحركة المبيعات والقصات.
- **تصدير التقارير إلى Excel (.xlsx)** بضغطة زر.
- **نظام صلاحيات متعدد المستخدمين**: (Admin, Manager, Employee, View Only).
- **قاعدة بيانات مركزية حقيقية** تدعم عمل عدة موظفين من أجهزة مختلفة في نفس الوقت.

---

## 🚀 طريقة التشغيل المحلي (Local)

1. الانتقال لمجلد المشروع:
   ```bash
   cd misbah-management-system
   ```

2. تشغيل السيرفر:
   ```bash
   python3 server.py
   ```
   أو عبر السكربت:
   ```bash
   ./start.sh
   ```

3. فتح الرابط في المتصفح:
   👉 **http://localhost:8080**

## 🔑 الحسابات الافتراضية

| المستخدم | كلمة المرور | الصلاحية |
| :--- | :--- | :--- |
| `admin` | `admin123` | **Admin (مدير النظام)** |
| `manager` | `manager123` | **Manager (مشرف مبيعات)** |
| `employee` | `emp123` | **Employee (موظف)** |
| `viewer` | `view123` | **View Only (مشاهدة فقط)** |

- لإنشاء أو تغيير كلمة مرور المدير من سطر الأوامر:
  ```bash
  python3 create_admin.py admin myNewPassword "اسم المدير" "965XXXXXXXX"
  ```

## 📁 هيكل ملفات المشروع

```
misbah-management-system/
├── server.py              # خادم الويب ومحرك الـ REST API
```
